# 星光小徑：森林的約定（Godot 4.3 開發中）

## 開啟方式
1. 以 Godot 4.3（或 4.x）開啟此資料夾中的 `project.godot`。
2. 按 F5 執行（主場景為 `scenes/forest.tscn`）。

## 目前完成（第一階段）
- 玩家四方向移動、走路動畫、碰撞系統（CharacterBody2D）。
- 森林地圖（以程式繪製的像素風替代素材），含樹木、湖泊、小路、花朵。
- NPC 互動（E 鍵）、逐句對話框（E / 空白鍵繼續）。
- 任務系統：小兔子「找回胡蘿蔔」、村民「花圃的花朵」。
- 地上物品撿取（E 鍵），背包開關（I 鍵）。
- 存讀檔：F5 存檔、F9 讀檔（位置、背包、任務進度、已撿取物品）。

## 操作
| 功能 | 按鍵 |
|---|---|
| 移動 | WASD / 方向鍵 |
| 互動、撿取 | E |
| 繼續對話 | 空白鍵 或 E |
| 背包 | I |
| 存檔 / 讀檔 | F5 / F9 |

## 專案結構
- `scripts/autoload/game_state.gd`：全域狀態（背包、任務、存讀檔、輸入對應、字型）。
- `scripts/data/`：物品與任務資料（與邏輯分開，方便擴充）。
- `scripts/player/`、`scripts/npc/`、`scripts/world/`：角色與場景物件。
- `scripts/ui/`：對話框、背包介面。
- `scripts/main.gd`：森林地圖的組裝與流程串接。

## 測試清單（請在 Godot 中逐項確認）
1. 開啟專案無錯誤、主場景可執行。
2. 四方向移動正常，不能穿過樹木、湖泊與地圖邊界。
3. 走向小兔子按 E：出現任務台詞；撿到胡蘿蔔後再按 E，獲得星星碎片。
4. 撿取地上物品後，背包（I）數量正確增加。
5. F5 存檔後，按 F9 讀檔：位置、背包、任務狀態與已撿物品都恢復。
6. 中文字是否正常顯示（若顯示為方框，請安裝 Noto Sans CJK TC 或在 game_state.gd 指定其他字型名稱）。

## 已知限制
- 目前所有地圖繪製都在 `main.gd` 的 `_draw()` 中，樹木會畫在角色下方（之後應拆成獨立的圖層節點）。
- 本次開發環境無法執行 Godot，因此以上功能尚未實機測試，請依測試清單驗證並回報錯誤。

## 第二階段更新：主選單、開場與劇情
- **1.0.7**：修正 player.gd 的型別錯誤（Node 沒有 global_position、interact 方法），這是導致 map_base.gd 無法載入的原因。
- **1.0.5**：修正 map_base.gd 的型別推斷錯誤（`var exit := MapExitScript.new()`），並移除不需要的 class_name MapBase。
- **1.0.4**：修正 map_base.gd 解析錯誤（動態成員存取、全域類別依賴），改用 preload。
- **1.0.3**：修正 `Could not resolve class "MapBase"`，地圖改用路徑繼承。
- **主選單**（`scenes/title.tscn`，現為啟動場景）：新遊戲、繼續遊戲（無存檔時停用）、設定（佔位）、離開。
- **開場**（`scenes/intro.tscn`）：打字機效果的旁白與旅行者獨白，E / 空白鍵逐段前進，ESC 跳過。
- **暫停選單**：森林中按 ESC 開啟，可繼續、存檔、返回主選單（未存檔的進度會遺失）。
- **劇情與台詞**：`scripts/data/story_data.gd` 集中管理開場與 NPC 台詞；狐狸與長老的對話會依任務進度與劇情旗標改變。新增「星光長老」，完成兩個任務後會揭露星光小徑的線索（旗標 `elder_revealed`）。
- 劇情旗標（`GameState.flags`）會一併存檔。

## 第二階段測試清單
1. 啟動後出現主選單，「繼續遊戲」在沒有存檔時為灰色。
2. 新遊戲 → 開場文字逐字出現，E 可跳到整句、再按一次進入下一句，ESC 直接跳過。
3. 進入森林後按 ESC 開啟暫停選單，「返回主選單」可回到標題畫面。
4. 完成兩個任務後與星光長老對話，出現揭露劇情的台詞，之後再對話內容改變。
5. 存檔後從主選單「繼續遊戲」，可回到存檔位置且劇情與任務狀態正確。

## 第三階段更新（1.0.2）：夜晚、引導、城市與更多角色
- **夜晚光影**：地圖以深藍色調呈現（CanvasModulate），玩家提著燈，路燈與螢火蟲點綴夜色；UI 不受影響。
- **新地圖架構**：所有地圖繼承 `MapBase`（`scripts/world/map_base.gd`），每張地圖只需提供資料（NPC、物品、出口、障礙物、繪製）。
- **引導系統**：左上角顯示目前目標，依操作依序引導移動、對話、撿取、背包、存檔；之後自動帶到任務與劇情。靠近互動物件時右下角顯示「E 互動」。
- **星光村（城市）**：可從森林東側小路進入。第一次抵達會觸發事件對話。
- **新角色**：森林的松鼠松果、精靈露露；星光村的村長老維、鐵匠石頭伯、旅店老闆娘小芽、小女孩米米、旅行商人阿珂、守衛阿力。
- **新任務**：
  - 鐵匠石頭伯：找一根木材 → 獲得燈籠
  - 小女孩米米：把燈籠交給她 → 獲得野莓，並揭開村子的燈火故事（旗標 `child_helped`）
- **存檔**：會記錄所在地圖，「繼續遊戲」會回到存檔時的地點。

## 第三階段測試清單
1. 開場後進入森林，畫面為夜晚色調，玩家周圍有光。左上角目標會隨操作改變。
2. 走到東側路口進入星光村，出現抵達事件對話。
3. 依序與鐵匠（需要森林的木頭）、小女孩（需要燈籠）互動，完成兩個任務。
4. 在星光村 F5 存檔，回主選單「繼續遊戲」應回到星光村。
5. 每位新角色頭上都有名字，對話內容會隨任務進度改變。
