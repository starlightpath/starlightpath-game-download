# Beta 1.0.9 — Visual & UI Update

- Seven collectible types now have distinct in-world drawings.
- Pause menu uses a dark starlight theme and redesigned buttons.
- Default language migration: old settings without an explicit language-selected marker now start in English. After choosing a language in Settings, it is preserved.
- Save slots, character customization, and achievements are retained.

## Testing
Godot 4.7.2 compilation and Windows export have not been tested in this environment.
